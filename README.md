### Abstract

This project casts the player as a photographer for a wildlife photography studio, "Wanderlust Studios", sent to photograph the wildlife and scenery in procedurally generated mountain ranges, along a trekking path taking them from the valley all the way to the top.
This project, build in the most recent Unreal Engine version at start time, is led to showcase the developer's proficiency with Procedural Content Generation - alongside general full-stack game design and programming - towards professional work in the gaming scene. 

The project will be intended primarily for PC deployments with controller support, although if I find enough time, I will also try and make builds for PlayStation and/or Xbox.

If this project caught your attention, I will kindly link towards my portfolio website, https://www.eisritter.net/ for a more in-depth insight into the work I do :)

Cheers, and have fun,
Josh / Eisritter

### Repository Structure:

### Use of Generative AI towards this project:
As a central topic in how we work today, I intend to be entirely transparent with the usage of Generative AI models towards this project:
> This being intended as a portfolio piece, this project was started with the intention of minimizing usage of GenAI tools in any way possible. No AI model is granted direct control over project files in any way towards this project.
> As a principle, the Project Lead dislikes the idea of giving creative control and influence to a predictive model without inherent creative abilities. Therefore no assets considered artistic (visual, geometric, or audio assets) will be generated using such models, and, while AI may help inform decisions and methodology, the direction and conception of the project is made by the Project Lead. 
> GenAI is considered by the Project Lead as a fair tool towards augmenting existing workflows, i.e. informing research and learning of concepts (always checked for accuracy), guiding the design of realistically scoped features, and assisting in debugging to decrypt error messages or complex errors.

### Project paradigms
As this project was made to showcase a fit in the games industry, I have decided to try and adopt several industry practises that make sense in solo projects:
- Test-Driven Development (TDD)
- Continuous Integration (CI)
- Performance Profiling
There are obviously more paradigms that would be worth adding in a team, that make less sense in a solo project: Agile iteration planning, Pair Programming, Standardized code reviews and pull requests.
